Responsive Image Gallery

A responsive and interactive Image Gallery built using HTML, CSS, and JavaScript as part of my Frontend Development Internship at CodeAlpha
The project demonstrates frontend development concepts such as responsive layouts, DOM manipulation, event handling, image filtering, search functionality, lightbox navigation, file uploading, and browser local storage.

Features

- Responsive image gallery
- Category-based image filtering
- Image search functionality
- Lightbox image preview
- Next and Previous image navigation
- Keyboard navigation using Arrow Keys and Escape
- Upload custom images
- Add image title and category
- Delete uploaded images
- Uploaded images persist after page refresh
- Smooth hover effects and transitions
- Mobile, tablet, and desktop responsive layout

Technologies Used

- HTML5 – Page structure and content
- CSS3 – Styling, Grid layout, animations, and responsive design
- JavaScript – Interactivity, filtering, search, lightbox, navigation, upload, and delete functionality
- LocalStorage – Saving uploaded images in the browser
- FileReader API – Reading uploaded image files
